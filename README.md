# 🍎 사과게임 (Apple Game)

드래그로 숫자 사과를 선택해 합이 **정확히 10**이 되면 사과가 사라지는 퍼즐 게임입니다.
제한 시간 120초 동안 최대한 많은 사과를 없애 점수를 올려보세요.

## 플레이 방법

1. `apple-game.html` 파일을 브라우저로 엽니다.
2. **게임 시작** 버튼을 누릅니다.
3. 마우스(또는 터치)로 드래그해 사각형 영역을 선택합니다.
4. 선택한 사과들의 숫자 합이 **10**이면 사라지고, 사라진 개수만큼 점수를 얻습니다.
5. 시간이 끝나면 최종 점수가 표시됩니다.

## 특징

- 17×10 격자, 1~9 랜덤 숫자 사과
- 드래그 중 실시간 선택 영역 및 합계 표시 (합이 10이면 초록색)
- 점수 / 남은 시간 / 타이머 진행 바
- 마우스 및 터치(모바일) 지원
- 외부 라이브러리 없는 단일 HTML 파일

## 기술 스택

- HTML / CSS / Vanilla JavaScript
